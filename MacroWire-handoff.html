MacroWire

The Macro Markets Reader — Kalshi macro prediction market analytics dashboard

This file is a self-contained brief for another AI. The live app is a React SPA; the entry HTML shell is at index.html and mounts into <div id="root">. Data comes from local parquet snapshots via a FastAPI backend, not live Kalshi on page load.

What it is

Read-only research dashboard showing Kalshi contract prices as implied probabilities (YES %), macro release calendar context, odds charts, mark-to-market P&L, regime-change detection, and per-series volatility analytics. Newspaper/editorial visual design (cream paper, serif headlines).

How to run

cd backend && .venv/bin/uvicorn app.main:app --reload --port 8000
npm run dev   # http://127.0.0.1:5173 — Vite proxies /api to port 8000

Data files (default): ~/files/kalshi_markets.parquet, kalshi_candlesticks.parquet, forexfactory_events.parquet, finnhub_news.parquet

Pages (hash routing)

PageURL hashContents
Markets #/ or empty 3-column layout: contract list (filter by CPI/Fed/Labour/Growth) · main chart + calendar strip + mark-to-market + regime changes · news/alerts sidebar. YES implied odds line chart with volume bars, event dashed lines (FOMC/CPI/NFP/PCE), optional spread overlay.
Volatility #volatility Dedicated page: pick a series (not all contracts at once), sort contracts by 14d σ high→low or low→high, rolling volatility chart per selected contract, table of contracts in that series with vol / YES / volume. Highlights most volatile contract in the series.

Key features

Market view

  • Filterable contract list grouped by series; threshold labels (e.g. T3.9 → ≥ 3.9%)
  • Days to expiry, bid/ask/spread/volume snapshot from parquet
  • YES close probability timeline with macro event vertical lines

Mark-to-market panel

  • Buy YES/NO, position size, entry date picker
  • Entry at ask on entry day; exit at bid today (open) or $1/$0 at settlement (closed)
  • P&L in points, %, and dollar terms

Regime changes

  • Flags single-day moves ≥ 8pp (absolute, not vol-normalized)
  • Tags nearest calendar release within 2 days

Volatility

  • 14-day standard deviation of daily close_prob changes, in percentage points
  • Per-contract rolling σ chart; series-filtered ranking table

Calendar & news

  • ForexFactory high-impact events strip
  • Finnhub headlines in right sidebar with move alerts

Important product decisions

  • Chart shows YES close (close_prob); event lines are dashed vertical reference lines at release dates
  • Mark-to-market uses ask-in / bid-out for tradable P&L insight, not close-to-close
  • Regime threshold is absolute ±8pp day-over-day, not relative to rolling vol
  • Volatility page filters by series so users compare bins within one event, not 2000 contracts at once
  • Settled-market realized P&L needs a result column in parquet when available; otherwise inferred from final candle
